🚀 Sistema de Navegación Responsive

Este es un ejemplo completo de implementación del sistema de navegación responsive con todas las funcionalidades requeridas.

📱 Mobile First

Diseño responsive que se adapta perfectamente a dispositivos móviles y desktop.

🔄 Persistencia

El estado del menú se mantiene entre navegaciones y recargas de página.

♿ Accesible

Soporte completo para navegación por teclado y lectores de pantalla.

✨ Smooth Scroll

Navegación suave entre secciones con compensación automática del header.

💰 Tarifas

Aquí se mostrarían las tarifas de los servicios. El enlace "Tarifas" en el menú se marca automáticamente como activo cuando navegas a esta sección.

Prueba hacer clic en diferentes enlaces del menú para ver cómo se actualiza el estado activo y cómo funciona el smooth scroll.

// Ejemplo de cómo se detecta el enlace activo function setActiveLink() { const currentHash = window.location.hash; elements.links.forEach(link => { const href = link.getAttribute('href'); if (href === currentHash) { link.classList.add('active'); link.setAttribute('aria-current', 'page'); } }); }

🏢 Empresa

Información sobre la empresa. Nota cómo el header permanece fijo en la parte superior y no interfiere con el contenido.

En dispositivos móviles (< 1024px), el menú se comporta como un overlay completo. En desktop (≥ 1024px), permanece como una barra horizontal.

Características técnicas:

  • Position sticky para el header
  • Z-index optimizado para evitar conflictos
  • Transiciones CSS suaves
  • Focus trap en mobile
  • Backdrop para cerrar el menú

🏔️ Excursiones

Contenido sobre excursiones. El sistema de navegación incluye las siguientes funcionalidades de teclado:

⌨️ Teclas de acceso

Escape: Cierra el menú en mobile
Tab: Navegación por elementos
Enter/Space: Activar enlaces

🎯 Focus Management

Focus trap automático en mobile cuando el menú está abierto. El foco se mantiene dentro del menú hasta que se cierra.

📞 Contacto

Información de contacto. El sistema guarda automáticamente el estado del menú en localStorage para mantener la experiencia del usuario.

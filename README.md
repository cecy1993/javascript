# Alta Pinta - Sitio Web de Excursiones en Bariloche

Este proyecto es un sitio web responsive para una empresa de excursiones en Bariloche. Incluye menú hamburguesa, galería con Grid, tablas de tarifas, contacto y más. 

## Estructura

- `index.html`: Página principal con galería y menú.
- `Pages/`: Páginas secundarias (Empresa, Tarifas, Excursiones, Contacto).
- `css/style.scss`: Estilos en SASS.
- `css/style.css`: Estilos compilados.
- `Images/`, `Videos/`, `Wireframe/`: Recursos multimedia y wireframes.

## Tecnologías
- HTML5, CSS3, SASS
- Flexbox y Grid para layout
- Menú hamburguesa responsive
- SEO básico (meta tags, alt en imágenes)

## Cómo compilar SASS
1. Instala SASS:
   ```
   npm install -g sass
   ```
2. Compila el archivo:
   ```
   sass css/style.scss css/style.css --no-source-map
   ```

## Publicar en GitHub Pages
1. Sube el proyecto a un repositorio en GitHub.
2. Ve a Settings > Pages.
3. Elige la rama principal y carpeta raíz (`/`).
4. Accede a la URL pública que te da GitHub.

## SEO
- Meta tags en el `<head>` de cada página.
- Imágenes con `alt` descriptivo.
- Títulos claros y contenido relevante.

Para consultas, usa la página de contacto o escribe a info@altapinta.com
